# v0.15.25 検証記録

- 工程を `⓪基本設定 → ①保管 → ②受付 → ③自動判定 → ④検算 → ⑤判断 → ⑥結果 → ⑦交付・記録` に分離した。
- ③自動判定は入力から「合包あり／合包なし」と処理の種類を表示し、操作ボタンを置かない構成にした。
- ④検算に「合包案を計算」を配置し、期間・服用時点・包数・重複の検算結果を表示する構成にした。
- ⑤判断に実施方法の選択、合包しない処理には各種の「報告を作成」ボタンを配置した。
- ⑥結果と⑦交付・記録まで、進行中の `▶`、完了の `✅`、背景色が新しい工程番号に追随することを確認した。
- 入力変更・設定変更・差戻し時の案内文と遷移先を新しい工程番号へ統一した。
- 自動検証 126件がすべて成功した。
